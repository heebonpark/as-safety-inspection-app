# AS 및 공사현장 안전점검 일일 보고

매일 공사현장 직원과 영상통화하거나 방문해서 작성하던 "AS 및 공사현장 일일점검 결과 보고" 종이 양식을
온라인으로 옮긴 도구입니다. [작업 전 TBM 및 위험성평가표](https://github.com/heebonpark/tbm-risk-assessment-app)
앱과 동일한 디자인/구조 패턴을 따르며, 같은 Firebase 프로젝트를 컬렉션만 분리해서 함께 씁니다.

## 구성
- 점검자 로그인(관리지사 + 이름, 비밀번호 없음) → 점검 보고서 작성 → 제출
- 관리자 로그인(비밀번호 0303) → 전체 내역 조회/검색/인쇄/CSV·ZIP 내보내기/삭제
- 체크리스트(안전모 착용, 사다리 아웃트리거/미끄럼방지, A형 사다리 안전고리, 사다리 안전수칙) + 항목별 현장사진 첨부(자동 압축) + 점검자 서명
